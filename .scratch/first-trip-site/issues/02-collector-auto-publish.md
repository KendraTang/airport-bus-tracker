# 02 — 收集器自動發佈

**What to build:** 每天的收集結束後，收集器自動把當天的原始資料與額度帳本 commit 並 push 到 GitHub。若部署管線已完成，push 之後網站就會自動更新。發佈失敗不能影響已存下的資料，下一次執行時要能把之前沒推上去的資料一起補推。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 收集結束（任何停止原因）後，只把收集器產生的資料檔加入 commit，不會誤加其他檔案
- [ ] commit 訊息為固定的中性格式，只包含日期與來源，不含個人資訊
- [ ] 沒有新資料時不產生空 commit
- [ ] push 失敗時寫入 log，不丟例外中斷流程，已存下的資料完整保留
- [ ] 前一次未推上去的 commit 會在下一次執行時一起推上去
- [ ] 遠端有新 commit（例如備援收集推上去的資料）時，能先同步再 push，不產生衝突
- [ ] 以臨時的近期 cron 排程實際驗證一次 commit 與 push，驗證後移除臨時排程，並記錄在測試紀錄文件中
