# 05 — 收集健康度與資料透明度

**What to build:** 網頁顯示每天每個來源是否收集成功、停止原因、輪詢次數與失敗次數，以及本月 TDX 額度用量與剩餘量。另外加上資料來源標示、最後更新時間，以及資料限制的說明（例如一分鐘輪詢的誤差、歷史資料無法回填）。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 每日收集狀態表：日期、來源、是否成功、停止原因、輪詢次數、失敗次數
- [ ] 本月額度用量與上限，計算方式與額度帳本一致
- [ ] 查證 TDX 的授權條款與標示要求，依要求在頁面上標示資料來源，查證結果記錄在 PRD 的待確認事項
- [ ] 頁面說明資料限制與各欄位意思，或連結到 repo 中的文件
- [ ] 最後更新時間以台灣時間顯示
