# 03 — 每日首班車紀錄表

**What to build:** 從原始 A2 事件找出每天的首班車，整理出實際發車時間，以及每一站的到站與離站時間。每個時間都標上可信度：實際觀測、缺漏、收集截止前未抵達。網頁上顯示每日紀錄表，一天一列，涵蓋往機場方向的所有站。

這張票也要用真實的清晨資料確認一件事：首班車抵達第一航廈時，是否一定會留下進站事件，還是可能在一分鐘的輪詢間隔內被離站事件覆蓋。若會被覆蓋，就以離站時間作為到站時間的上限，並明確標示。

**已決定的缺漏處理方式：** 每個站點時間分為觀測、範圍、推算、缺漏四種狀態（定義見 PRD 的資料可信度一節）。共用的推算邏輯與網頁上的呈現方式，已經在顯示第三方 App 紀錄時建立，這張票沿用即可。

**Blocked by:** 01；另外需要至少一個清晨的真實收集資料
